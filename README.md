# LINGNAN UNIVERSITY PROJECTS

岭南大学课程作业仓库。按**课程代码**分文件夹存放每次作业。

## 目录结构

```text
LINGNAN-UNIVERSITY-PROJECTS/
├── README.md
├── CDS-703/          # 课程 CDS-703
│   ├── README.md
│   └── …               # 各次作业子文件夹
└── …                   # 其他课程（如 CDS-xxx）
```

## 新增作业

1. 在对应课程文件夹下新建子目录，建议命名：`作业简称-日期` 或 `Week-n-主题`。
2. 把源码、报告、反思等放在该子目录内。
3. `git add` → `git commit` → `git push`。
